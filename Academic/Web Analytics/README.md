# Web Analytics Coursework

This coursework focuses on using data to understand performance and support business decisions. The projects cover education, finance, social media, YouTube, and website analytics, with attention to dashboards, data collection, privacy, and clear communication.

## File Guide

### `Book1.xlsx`

[Open the sample financial workbook](Book1.xlsx)

An Excel workbook containing sample financial data and chart inputs used in the visualization coursework. The data supports comparisons such as portfolio value, asset allocation, risk, and return. This file demonstrates how a structured dataset can support dashboard planning and business reporting.

### `K.McMahon_Deliverable1_10122025.docx`

[Open the Georgia State University Analytics Case Study](K.McMahon_Deliverable1_10122025.docx)
