# Quality Assurance Coursework

This series follows a realistic software quality lifecycle using a Student Grading System and a Hangman desktop application. It progresses from requirements and planning to execution, defect reporting, and automation strategy.

## Student Grading System Project

- [Configuration Management Plan](K.McMahon_Module01CourseProject_1102026.docx): defines roles, controlled items, baselines, change review, release handling, and version control.
- [Software Requirements Specification](K.McMahon_Module02CourseProject_1182026.docx): documents functional and non-functional requirements for course, student, assessment, and grade management.
- [Complete Software Test Plan](K.McMahon_Module03CourseProject_1242026.docx): translates the requirements into functional and non-functional tests for core user workflows.
- [Test Execution Report](K.McMahon_Module04CourseProject_292026.docx): records manual black-box results for course, student, assessment, grade, and performance behavior.
- [Defect Report](K.McMahon_Module06CourseProject_2102026.docx): documents reproducible Student Grading System issues with severity, expected behavior, actual behavior, and traceability.

## Hangman Testing Project

- [Software Test Plan](K.McMahon_Module02Asssignment_1182026.docx): covers gameplay, input validation, response time, and repeated-action stability.
- [Software Test Report](K.McMahon_Module04Asssignment_292026.docx): records execution results and identifies the failed end-of-game behavior.
- [Defect Reports](K.McMahon_Module06Asssignment_292026.docx): converts observed Hangman failures into reproducible developer-ready defect records.

## QA Process and Automation Presentations

- [Software Quality Assurance Processes](K.McMahon_Module03Assignment_1252026.pptx): explains process definition, training, implementation, audits, CMMI, ISO 9000, and Six Sigma.
- [Test Automation Framework Recommendations](K.McMahon_Module05Assignment_282026.pptx): compares Playwright, Cypress, and Selenium and explains how project needs guide framework selection.

The duplicate Module 3 assignment document is retained because it is part of the original course submission set.
