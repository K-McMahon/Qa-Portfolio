# QA Analyst Portfolio

## About Me

I am a computer science graduate with professional experience in operations, project coordination, process improvement, employee training, troubleshooting, quality assurance in a production environment, and customer service.

I am transitioning into software quality assurance and data analysis. This portfolio demonstrates my ability to plan tests, execute test cases, document software defects, analyze results, test APIs, and develop basic automated tests.

## Portfolio Contents

### Test Plans
Documentation describing the scope, objectives, testing approach, environment, risks, and completion criteria for each testing project.

### Test Cases
Detailed test cases containing preconditions, test steps, expected results, actual results, and execution status.

### Bug Reports
Defect reports containing reproduction steps, expected behavior, actual behavior, severity, priority, environment details, and supporting evidence.

### Test Execution Reports
Summaries of completed testing activities, passed and failed test cases, discovered defects, and testing conclusions.

### API Testing
API requests, test scripts, response validation, and Postman collections.

### Automation
Basic automated tests developed using tools such as Playwright or Selenium.

### Screenshots
Supporting evidence for defects, test execution, and project results.
