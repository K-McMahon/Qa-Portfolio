01 / THE CHALLENGE

Context matters.

The validator collects exactly 100 records, verifies unique IDs and usable timestamps, checks newest-to-oldest order, and generates an HTML report designed for a reviewer who was not watching the test run.

Important context

The passing result represents a recorded run, not a claim about the current live order of Hacker News.
