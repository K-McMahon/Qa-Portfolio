# GitHub Pages QA portfolio website

## Current publishing configuration

GitHub Pages is configured to publish from the **root of the main branch**, as confirmed by the Pages build log on November 6, 2026 (Jekyll action used `source: .`).

Public homepage: https://k-mcmahon.github.io/Qa-Portfolio/

**The website must have `index.html`, `projects/`, `styles.css`, `site.js`, `about.html`, `assets/` and `media/` at the repository root to be served at the public site URLs.** These root website files are copies of the files originally authored under `docs/`. They are intentionally mirrored in order to support the current Pages configuration without changing repository Settings.

When editing the site, keep the root website files and their `docs/` copies synchronized, or switch Pages to `main /docs` in GitHub settings and thereafter maintain only `docs/`. Do not switch to `main /docs` while root-only changes exist.

Original portfolio and project README files are preserved and are the source of truth for evidence. Website metrics are dated historical checkpoints, not live CI. Ark of Amerigo is still in development.
